
## 🧩 What Is the Logger in NestJS?

The **Logger** in NestJS is a **built-in utility** for recording messages about what’s happening inside your application — like:

- When the app starts
    
- When requests are handled
    
- When errors occur
    
- When specific actions or events happen
    

It helps with:

- 🧠 Debugging issues
    
- 📊 Monitoring behavior
    
- 🧩 Tracing requests and system events
    

---

## ⚙️ Basic Usage

NestJS includes a built-in logger class:

```ts
import { Logger } from '@nestjs/common';
```

You can create one inside any class or service:

```ts
import { Injectable, Logger } from '@nestjs/common';

@Injectable()
export class UsersService {
  private readonly logger = new Logger(UsersService.name); // 👈 tag with class name

  findAll() {
    this.logger.log('Fetching all users...');     // Standard log
    this.logger.warn('This is a warning');        // Warning
    this.logger.error('Something went wrong!');   // Error
    this.logger.debug('Debugging details');       // Debug (visible in dev)
    this.logger.verbose('More detailed info');    // Verbose (optional)

    return ['Alice', 'Bob'];
  }
}
```

---

## 🧠 Log Levels

NestJS supports **five log levels**:

|Level|Description|Example|
|---|---|---|
|`log`|General purpose logs|`this.logger.log('Server started')`|
|`error`|Critical errors|`this.logger.error('DB connection failed')`|
|`warn`|Warnings|`this.logger.warn('Memory usage high')`|
|`debug`|Developer info (usually disabled in prod)|`this.logger.debug('Cache miss')`|
|`verbose`|Most detailed (used in tracing)|`this.logger.verbose('User data parsed')`|

---

## 🧩 Global Logging (Application-Wide)

In your `main.ts`, NestJS automatically uses a global logger:

```ts
import { NestFactory, Logger } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  const logger = new Logger('Bootstrap');
  await app.listen(3000);

  logger.log('🚀 Application running on http://localhost:3000');
}
bootstrap();
```

---

## ⚙️ Controlling Log Levels

You can tell NestJS which log levels to show when starting the app:

```ts
const app = await NestFactory.create(AppModule, {
  logger: ['error', 'warn', 'log'], // 👈 Only show these levels
});
```

Available options:

- `['log', 'error', 'warn', 'debug', 'verbose']`
    

For example, in **development**, you might show all logs;  
in **production**, only errors and warnings.

## 🧠 Custom Logger (Optional)

You can also create your own logger that integrates with services like:

- 📜 Winston (structured logs)
    
- 🪣 AWS CloudWatch
    
- 💾 File-based logs
    

Example using **Winston**:

```bash
npm install nest-winston winston
```

Then:

```ts
import { WinstonModule } from 'nest-winston';
import * as winston from 'winston';

const app = await NestFactory.create(AppModule, {
  logger: WinstonModule.createLogger({
    transports: [
      new winston.transports.Console(),
      new winston.transports.File({ filename: 'app.log' }),
    ],
  }),
});
```

✅ Now logs go both to console and `app.log`.

---

## 🧩 Logging HTTP Requests (Optional)

If you want to log every incoming request, use a middleware like `morgan`:

```bash
npm install morgan
```

Then in `main.ts`:

```ts
import * as morgan from 'morgan';

app.use(morgan('dev'));
```
