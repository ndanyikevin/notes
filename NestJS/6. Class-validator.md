
In **NestJS**, **`class-validator`** is a powerful library used to **validate incoming data** — especially data defined in your **DTOs (Data Transfer Objects)**.

---

## ✅ In simple terms:

> `class-validator` checks if the data coming from a client (like a POST request body) **meets the required rules** you define in your DTO class.

It helps you ensure that:

- Required fields are present
    
- Strings are valid emails
    
- Numbers are within range
    
- Enums match allowed values
    
- etc.
    

---

## 🔧 Installation

To use it, install two libraries (they work together):

```bash
npm install class-validator class-transformer
```

---

## 🧩 Example — DTO with `class-validator`

```ts
import { IsString, IsEmail, IsEnum, IsNotEmpty } from 'class-validator';

export class CreateUserDto {
  @IsNotEmpty()
  @IsString()
  name: string;

  @IsEmail()
  email: string;

  @IsEnum(['admin', 'engineer', 'intern'])
  role: 'admin' | 'engineer' | 'intern';
}
```

---

## ⚙️ Enabling Validation in Your App

In your **`main.ts`** file, enable the validation pipe:

```ts
import { ValidationPipe } from '@nestjs/common';
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  // Enable global validation
  app.useGlobalPipes(new ValidationPipe());

  await app.listen(3000);
}
bootstrap();
```

Now, NestJS automatically validates every incoming request body against your DTOs.

## 🧠 Example Request

### ✅ Valid Request

```json
{
  "name": "Alice Kimani",
  "email": "alice.kimani@example.com",
  "role": "engineer"
}
```

### ❌ Invalid Request

```json
{
  "name": "",
  "email": "invalid_email",
  "role": "manager"
}
```

Response:

```json
{
  "statusCode": 400,
  "message": [
    "name should not be empty",
    "email must be an email",
    "role must be a valid enum value"
  ],
  "error": "Bad Request"
}
```

## ✅ Commonly Used Decorators

|Decorator|Description|
|---|---|
|`@IsString()`|Value must be a string|
|`@IsInt()`|Value must be an integer|
|`@IsEmail()`|Must be a valid email address|
|`@IsBoolean()`|Must be true or false|
|`@IsOptional()`|Field is not required|
|`@MinLength(n)` / `@MaxLength(n)`|Control string length|
|`@Min(n)` / `@Max(n)`|Control number range|
|`@IsEnum(EnumType)`|Must match an enum value|
|`@IsNotEmpty()`|Field cannot be empty|

## 🔒 Why It’s Important

|Benefit|Description|
|---|---|
|✅ **Security**|Prevents malformed or malicious data|
|✅ **Reliability**|Ensures backend receives valid data|
|✅ **Clean code**|Moves validation rules out of controllers|
|✅ **Error handling**|Automatic 400 responses with detailed messages|

---

### 🔁 Works Perfectly with:

- DTOs (`CreateUserDto`, `UpdateUserDto`, etc.)
    
- `ValidationPipe` in NestJS
    
- `class-transformer` (for automatic object mapping)

|**Result**|Automatic 400 errors for invalid requests|
