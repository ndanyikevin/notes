
## 🧩 What Is CORS?

**CORS (Cross-Origin Resource Sharing)** is a **security mechanism** built into web browsers that **controls which external domains** are allowed to **access your API**.

---

### 💡 Example Scenario

Let’s say:

- Your **NestJS backend** runs on `http://localhost:3000`
    
- Your **SolidJS frontend** runs on `http://localhost:5173`
    

When your frontend tries to call:

```js
fetch('http://localhost:3000/users')
```

The browser says:

> “Wait — this is a **cross-origin request** (different ports/domains).  
> Is this allowed?”

Then it checks your backend’s **CORS policy** (the headers you send).

If your backend doesn’t explicitly allow it, you’ll get this error in the browser console:

```
Access to fetch at 'http://localhost:3000/users' from origin 'http://localhost:5173' 
has been blocked by CORS policy.
```

---

## ⚙️ Enabling CORS in NestJS

By default, NestJS uses **Express.js** under the hood — so enabling CORS is very easy.

In your `main.ts` file:

```ts
async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  // ✅ Enable CORS globally
  app.enableCors();

  await app.listen(3000);
}
bootstrap();
```

That simple command:

- Adds the right headers (`Access-Control-Allow-Origin`, etc.)
    
- Allows all domains by default (`*`)
    

---

## ⚙️ Restricting CORS (Recommended for Production)

You usually don’t want to allow _everyone_.  
You can configure it like this:

```ts
app.enableCors({
  origin: ['http://localhost:5173', 'https://yourfrontend.com'],
  methods: ['GET', 'POST', 'PATCH', 'DELETE'],
  credentials: true,
});
```

### 🔍 Explanation:

|Option|Meaning|
|---|---|
|**origin**|Allowed domains (can be a string, regex, or function)|
|**methods**|Allowed HTTP methods|
|**credentials**|Allow cookies or auth headers|

---

## 🧠 Example Full Setup

```ts
async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.enableCors({
    origin: ['http://localhost:5173'],
    methods: ['GET', 'POST', 'PATCH', 'DELETE'],
    allowedHeaders: ['Content-Type', 'Authorization'],
    credentials: true,
  });

  await app.listen(3000);
  console.log('✅ Server running on http://localhost:3000');
}
bootstrap();
```

## 🧩 Why CORS Matters

|Feature|Description|
|---|---|
|**Security**|Prevents malicious websites from calling your API|
|**Frontend Communication**|Allows your frontend (on another domain) to interact with your backend|
|**Cookies & Auth**|Controls whether authentication info (like tokens) can be shared|

---

### 🚫 Without CORS

Frontend → Backend request gets blocked by the browser.

### ✅ With CORS

Backend tells the browser:

> “Yes, this frontend is allowed to call me.”

---

## ⚙️ Bonus — Per Route CORS (Optional)

You can even enable CORS **for specific controllers**:

```ts
import { Controller, Get } from '@nestjs/common';
import { Cors } from '@nestjs/common/decorators/http/cors.decorator';

@Controller('public')
@Cors({ origin: '*' }) // 👈 only for this route
export class PublicController {
  @Get()
  findAll() {
    return ['open data'];
  }
}
```

## ✅ Summary

|Concept|Meaning|
|---|---|
|**CORS**|A browser security policy that controls cross-origin requests|
|**Default state**|Disabled unless enabled with `app.enableCors()`|
|**Main use case**|Allow frontend (e.g. SolidJS) to call backend (NestJS)|
|**Set location**|`main.ts`|
|**Best practice**|Allow only trusted origins in production|
