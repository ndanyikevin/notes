
## 🚀 What is **`class-transformer`** in NestJS?

`class-transformer` is a library that works hand-in-hand with `class-validator`.

It helps you **transform plain JavaScript objects** (like raw JSON from HTTP requests) **into instances of TypeScript classes** — such as your **DTOs** — and vice versa.

---

## ✅ In simple terms

> `class-transformer` converts plain data (from user requests or databases) into actual **class instances** that can be **validated**, **typed**, and **manipulated** safely.

---

## 🧠 Why It Matters

When you send a request like:

```json
{
  "name": "Alice",
  "email": "alice@example.com",
  "role": "engineer"
}
```

NestJS receives this as a **plain JavaScript object**.

But your DTO (e.g., `CreateUserDto`) is a **class**.  
To use `class-validator`, you must first **transform** that plain object into an instance of the DTO class.

That’s exactly what `class-transformer` does automatically — through the **`ValidationPipe`**.

---


## 🧩 Example — Using with a DTO

```ts
import { IsString, IsEmail } from 'class-validator';
import { Exclude, Expose, Transform } from 'class-transformer';

export class UserDto {
  @IsString()
  name: string;

  @IsEmail()
  email: string;

  @Expose() // explicitly include this field in responses
  role: string;

  @Exclude() // hide this field from responses
  password: string;

  @Transform(({ value }) => value.toLowerCase()) // auto-transform input
  username: string;
}
```

---

## ⚙️ How It Works with `ValidationPipe`

In your `main.ts`:

```ts
import { ValidationPipe } from '@nestjs/common';
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.useGlobalPipes(
    new ValidationPipe({
      transform: true, // ✅ enables class-transformer
      whitelist: true, // ✅ strips extra properties not in the DTO
    }),
  );

  await app.listen(3000);
}
bootstrap();
```

Now every time you send a request body like:

```json
{
  "name": "ALICE",
  "email": "ALICE@EXAMPLE.COM",
  "username": "Alice123",
  "password": "secret",
  "extraField": "ignoreThis"
}
```

You’ll get:

```ts
UserDto {
  name: 'ALICE',
  email: 'alice@example.com',
  username: 'alice123',
  role: undefined // (if not provided)
}
```

✅ Password is excluded  
✅ Extra field is stripped  
✅ Username is transformed to lowercase

---

## ✨ Common Decorators from `class-transformer`

|Decorator|Description|
|---|---|
|`@Expose()`|Marks a field to be included when transforming to plain object|
|`@Exclude()`|Excludes a field (useful for hiding passwords)|
|`@Transform()`|Custom transformation for a property|
|`plainToInstance()`|Converts a plain object → class instance|
|`instanceToPlain()`|Converts a class instance → plain object (for responses)|

---

## 🧩 Example – Manual Transformation

```ts
import { plainToInstance } from 'class-transformer';

const userPlain = {
  name: 'Alice',
  email: 'alice@example.com',
  password: 'secret',
};

const user = plainToInstance(UserDto, userPlain);
console.log(user instanceof UserDto); // true
```

## ✅ Summary

|Concept|Description|
|---|---|
|**class-transformer**|Converts plain JS objects into class instances|
|**Used with**|`class-validator` and `ValidationPipe`|
|**Main Benefit**|Enables automatic transformation + cleaner validation|
|**Decorators**|`@Expose()`, `@Exclude()`, `@Transform()`|
|**Typical Use Case**|Request validation, response shaping, data sanitization|

---

**In short:**

- `class-validator` → validates data
    
- `class-transformer` → transforms data
    

Together, they make DTOs **type-safe**, **validated**, and **clean** 💪
