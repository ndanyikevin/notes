Setting up a new **NestJS** project is straightforward. Here’s a step-by-step guide:

---

### ✅ **1️⃣ Install Node.js**

Make sure Node.js (v16+ recommended) is installed.  
Check version:

```bash
node -v
npm -v
```

---

### ✅ **2️⃣ Install the NestJS CLI**

Use npm or yarn:

```bash
npm i -g @nestjs/cli
```

or

```bash
yarn global add @nestjs/cli
```

---

### ✅ **3️⃣ Create a New Project**

```bash
nest new my-project
```

Nest will ask which package manager you prefer → choose **npm**, **yarn**, or **pnpm**.

This will generate a folder `my-project` with the standard NestJS structure:

```
src/
 ├── app.controller.ts
 ├── app.module.ts
 └── app.service.ts
```

---

### ✅ **4️⃣ Navigate to the Project**

```bash
cd my-project
```

---

### ✅ **5️⃣ Run the App**

```bash
npm run start:dev
```

Your API now runs at:  
👉 [http://localhost:3000](http://localhost:3000/)

---

### 📌 Common Additional Commands

|Action|CLI Command|
|---|---|
|Generate a module|`nest generate module users`|
|Generate a controller|`nest generate controller users`|
|Generate a service|`nest generate service users`|
|Add Prisma|`npm install prisma --save-dev` & init afterwards|
|Add TypeORM|`npm install @nestjs/typeorm typeorm pg`|

Example:

```bash
nest g module auth
nest g controller auth
nest g service auth
```

---

### ✅ Folder Structure Best Practice for Real Projects

```
src/
 ├── modules/
 │    ├── users/
 │    │    ├── users.controller.ts
 │    │    ├── users.service.ts
 │    │    ├── users.module.ts
 │    │    └── dto/
 ├── common/
 ├── app.module.ts
```
