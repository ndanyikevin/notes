
In **NestJS**, **pipes** are powerful tools used to **transform** and **validate** data before it reaches your route handlers (controllers).

---

## 🧩 In Simple Terms:

> A **pipe** is a class that runs **before your controller method executes**, allowing you to **transform input data** or **validate it** automatically.

---

## ✅ Two Main Purposes of Pipes

|Purpose|Description|
|---|---|
|**1. Validation**|Ensure the data meets certain rules (e.g., correct type, valid DTO)|
|**2. Transformation**|Automatically convert input data into the desired format or type|

---

## 🔧 Example: Pipes in Action

```ts
@Get(':id')
getUser(@Param('id', ParseIntPipe) id: number) {
  return this.usersService.findOne(id);
}
```

Here’s what happens:

- The `id` comes as a **string** from the URL (e.g., `"3"`)
    
- `ParseIntPipe` **transforms** it into a number (`3`)
    
- If it’s not a valid number, NestJS throws a **400 Bad Request**
    

---

## 🧱 Common Built-in Pipes

|Pipe|Purpose|
|---|---|
|`ValidationPipe`|Validates request data using `class-validator`|
|`ParseIntPipe`|Converts string → number|
|`ParseBoolPipe`|Converts `"true"`/`"false"` → boolean|
|`ParseUUIDPipe`|Ensures a string is a valid UUID|
|`DefaultValuePipe`|Assigns a default if no value provided|

---

## 🧠 Example — ValidationPipe with DTO

### DTO

```ts
import { IsEmail, IsString } from 'class-validator';

export class CreateUserDto {
  @IsString()
  name: string;

  @IsEmail()
  email: string;
}
```

### Controller

```ts
@Post()
createUser(@Body(new ValidationPipe()) body: CreateUserDto) {
  return this.userService.create(body);
}
```

If you send invalid data:

```json
{ "name": 123, "email": "notanemail" }
```

NestJS automatically responds with:

```json
{
  "statusCode": 400,
  "message": [
    "name must be a string",
    "email must be an email"
  ],
  "error": "Bad Request"
}
```

## ⚙️ Global ValidationPipe Setup (Best Practice)

In `main.ts`:

```ts
import { ValidationPipe } from '@nestjs/common';
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.useGlobalPipes(
    new ValidationPipe({
      transform: true, // ✅ enables class-transformer
      whitelist: true, // ✅ removes unexpected fields
      forbidNonWhitelisted: true, // ❌ throws error if unknown fields present
    }),
  );

  await app.listen(3000);
}
bootstrap();
```

Now every request across your app is validated automatically.

## 🧩 Example — Custom Pipe

You can also create your own pipe.

```ts
import { PipeTransform, Injectable, BadRequestException } from '@nestjs/common';

@Injectable()
export class UppercasePipe implements PipeTransform {
  transform(value: any) {
    if (typeof value !== 'string') {
      throw new BadRequestException('Value must be a string');
    }
    return value.toUpperCase();
  }
}
```

Use it:

```ts
@Get(':name')
getUser(@Param('name', UppercasePipe) name: string) {
  return `Hello, ${name}`;
}
```

Request: `/users/alice` → Response: `"Hello, ALICE"`

## ✅ Summary

|Concept|Description|
|---|---|
|**Pipe**|A class that transforms or validates incoming data|
|**Runs**|Before your route handler executes|
|**Common Pipes**|`ValidationPipe`, `ParseIntPipe`, `ParseBoolPipe`, etc.|
|**Custom Pipes**|You can create your own logic using `PipeTransform`|
|**Works with DTOs**|Often used with `class-validator` and `class-transformer`|

---

### 🧠 TL;DR

- **Validation** → Checks if data is valid
    
- **Transformation** → Converts data into the right type
    
- **Custom Pipes** → Add your own pre-controller logic
