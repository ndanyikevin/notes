A **forward proxy** is the _opposite perspective_ of a reverse proxy.

Instead of sitting in front of **servers**, a forward proxy sits in front of **clients**.

---

## Simple idea

```
Client → Forward Proxy → Internet (servers)
```

The **server does NOT know the real client** — it only sees the proxy.

---

## What a forward proxy does

- Acts **on behalf of clients**
    
- Clients must be **configured to use it**
    
- Controls **outgoing traffic**
    

---

## Why use a forward proxy?

### 1. Hide client identity

Websites see the proxy’s IP, not the user’s.

Example:

- VPN
    
- Corporate proxy
    
- School proxy
    

---

### 2. Access control

- Block websites (e.g. social media)
    
- Allow only specific domains
    
- Time-based access rules
    

---

### 3. Caching

If many users request the same site:

- proxy caches the response
    
- speeds things up
    
- reduces bandwidth
    

---

### 4. Logging & monitoring

Admins can see:

- which sites are visited
    
- how much data is used
    

---

### 5. Security filtering

- Block malware domains
    
- Inspect traffic
    
- Prevent data exfiltration
    

---

## Basic forward proxy flow

```
Browser (configured to use proxy)
      ↓
Forward Proxy (Squid / NGINX / Envoy)
      ↓
example.com
```

---

## Forward proxy vs Reverse proxy

|Feature|Forward Proxy|Reverse Proxy|
|---|---|---|
|Positioned in front of|Clients|Servers|
|Who configures it|Client|Server|
|Hides|Client|Backend|
|Common use|VPN, firewall|Load balancing, HTTPS|
|Seen by end user|Yes|No|

---

## Forward proxy with NGINX (simple example)

> ⚠️ NGINX is **not ideal** for forward proxy, but it _can_ do basic HTTP proxying.

```nginx
server {
    listen 3128;

    resolver 8.8.8.8;

    location / {
        proxy_pass http://$http_host$request_uri;
    }
}
```

Browser config:

```
HTTP Proxy: proxy-ip
Port: 3128
```

## Real-world analogy

### Forward proxy

You ask a friend to:

- browse the internet for you
    
- bring back information
    
- websites only see your friend
    

### Reverse proxy

A company receptionist:

- receives visitors
    
- sends them to the correct department
