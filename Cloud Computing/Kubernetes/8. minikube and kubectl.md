**Minikube** is a tool that lets you run a **full Kubernetes cluster on your local computer**.

> **Minikube = Kubernetes for learning, testing, and development**

---

## Why Minikube exists

Setting up a real Kubernetes cluster is:

- complex
    
- expensive
    
- overkill for learning
    

Minikube solves this by running:

- the **control plane**
    
- **worker node(s)**  
    inside a **VM or container** on your machine.
    

---

## What Minikube gives you

- A **real Kubernetes cluster**
    
- Works on **Windows, macOS, Linux**
    
- Uses Docker, Podman, or a VM as the driver
    
- Perfect for **practice and experiments**
    

---

## How it works (simple)

```
Your Laptop
└── Minikube
    └── Kubernetes Cluster
        └── Node(s)
            └── Pods
```

---

## What Minikube is used for

✅ Learning Kubernetes concepts  
✅ Testing manifests (Deployment, Service, Ingress)  
✅ Developing apps locally  
❌ Not for production

---

## Common Minikube commands

```bash
minikube start
kubectl get nodes
kubectl get pods -A
minikube dashboard
```

Expose a service:

```bash
minikube service api-service
```

---

## Minikube + Ingress

Enable ingress:

```bash
minikube addons enable ingress
```

Then you can test real domains locally.
