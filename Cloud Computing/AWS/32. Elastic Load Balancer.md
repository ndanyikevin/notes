# ⚖️ **Elastic Load Balancer (ELB)** — Clear Notes

**Elastic Load Balancer (ELB)** is an AWS service that **automatically distributes incoming traffic** across multiple targets (EC2 instances, containers, IPs, or Lambda) to ensure **high availability, fault tolerance, and scalability**.

---

## ✅ Why ELB Is Important

ELB helps you:

- Avoid **single points of failure**
    
- Improve **application availability**
    
- Handle **traffic spikes automatically**
    
- Perform **health checks** and route traffic only to healthy targets
    

---

## 🔁 How ELB Works (Simple)

1. Users send requests to your app
    
2. ELB receives the traffic
    
3. ELB checks which targets are healthy
    
4. ELB forwards requests to healthy targets only
    

➡️ If one instance fails, traffic is automatically rerouted.

---

## 🧩 Types of Elastic Load Balancers

### 1️⃣ **Application Load Balancer (ALB)** — Layer 7

- Works at **HTTP/HTTPS level**
    
- Routes traffic based on:
    
    - URL path (`/api`, `/images`)
        
    - Hostname (`api.example.com`)
        
    - Headers
        
- Supports:
    
    - Containers (ECS, EKS)
        
    - Lambda functions
        
    - WebSockets
        

✅ Best for  
🌐 Web applications  
🔀 Microservices  
🧠 Smart routing logic

---

### 2️⃣ **Network Load Balancer (NLB)** — Layer 4

- Works at **TCP/UDP level**
    
- Extremely **fast and low latency**
    
- Handles **millions of requests per second**
    
- Supports **static IPs**
    

✅ Best for  
⚡ High-performance apps  
🎮 Gaming  
📡 Real-time systems  
📶 VoIP

---

### 3️⃣ **Gateway Load Balancer (GWLB)**

- Used for **security appliances**
    
- Distributes traffic to:
    
    - Firewalls
        
    - IDS/IPS
        
    - Deep packet inspection systems
        

✅ Best for  
🛡️ Centralized security  
🔥 Network inspection

---

### ❌ Classic Load Balancer (CLB)

- Legacy
    
- Avoid for new applications
    

---

## 🧪 Health Checks (Very Important)

ELB continuously checks:

- Port
    
- Protocol
    
- Response codes
    

If a target fails:  
❌ Removed from traffic  
Once healthy:  
✅ Added back automatically

---

## 🔐 Security Features

- Integrates with **Security Groups**
    
- Supports **SSL/TLS termination**
    
- Works with **AWS WAF** (ALB)
    
- Supports **IAM permissions**
    

---

## 🧠 ELB vs Auto Scaling

|Feature|ELB|Auto Scaling|
|---|---|---|
|Distributes traffic|✅|❌|
|Adds/removes servers|❌|✅|
|High availability|✅|✅|

➡️ **They are best used together**

---

## 📌 Exam Tips

- **ALB** → HTTP/HTTPS + smart routing
    
- **NLB** → Ultra-fast TCP/UDP
    
- **GWLB** → Security appliances
    
- **ELB is regional** and works across AZs
