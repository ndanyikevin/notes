To automate deployment for your **Bun + Hono + Solid Start** stack, the industry standard is **GitHub Actions**. It acts like a robot that waits for you to "push" code to GitHub, then logs into your VPS and runs the update commands for you.1

Here is the complete setup to automate one of your systems (e.g., Brandflare).

### 1. Generate an SSH Key for GitHub2

First, you need to give GitHub "keys" to your server so it can log in without a password.3

1. On your VPS, run:
    
    ssh-keygen -t ed25519 -C "github-actions"
    
    (Press Enter for all prompts to keep defaults and no passphrase).
    
2. Add the key to authorized list:
    
    cat ~/.ssh/id_ed25519.pub >> ~/.ssh/authorized_keys
    
3. Copy your Private Key:
    
    cat ~/.ssh/id_ed25519
    
    Copy the entire block of text (starts with -----BEGIN OPENSSH PRIVATE KEY-----).4
    

---

### 2. Store Secrets in GitHub

Go to your GitHub repository → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**.5

Add these three secrets:

- `SSH_PRIVATE_KEY`: (Paste the private key you just copied).6
    
- `SERVER_IP`: (Your Hostinger VPS IP).
    
- `SERVER_USER`: `root`
    

---

### 3. Create the Automation Workflow

In your project folder (locally on your computer), create a new file at `.github/workflows/deploy.yml`.

**Copy and paste this full component:**

YAML

```
name: Deploy to VPS

on:
  push:
    branches:
      - main  # Runs whenever you push to the main branch

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout code
        uses: actions/checkout@v4

      - name: Deploy via SSH
        uses: appleboy/ssh-action@v1.0.3
        with:
          host: ${{ secrets.SERVER_IP }}
          username: ${{ secrets.SERVER_USER }}
          key: ${{ secrets.SSH_PRIVATE_KEY }}
          script: |
            cd /var/www/brandflare
            git pull origin main
            bun install
            bun run build
            # This restarts your backend and frontend in PM2
            pm2 restart brandflare-api brandflare-web
```

---

### 4. How it Works

1. You finish a feature locally and run `git push origin main`.
    
2. GitHub sees the push and starts the "Workflow" you just created.
    
3. GitHub securely logs into your VPS using the `SSH_PRIVATE_KEY`.
    
4. It navigates to your folder, pulls the new code, installs dependencies with **Bun**, builds the site, and tells **PM2** to restart the apps.
    

### Important: The First Deployment

Before the automation works, you must manually "clone" the repo to the VPS folder once so the folder exists:7

Bash

```
cd /var/www
git clone https://github.com/your-username/brandflare.git
```

- [ ] SSH key generated and added to `authorized_keys`.
    
- [ ] Private key added to GitHub Secrets.
    
- [ ] `deploy.yml` file created in your repo.8
