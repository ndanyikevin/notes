To point your domains to your apps and secure them with **SSL (HTTPS)**, we will use **Nginx** as a traffic controller and **Certbot** (by Let's Encrypt) for free, automatic security certificates.

Since you are running three systems, we will create three separate configuration files. This keeps things organized.

### 1. Install Nginx and Certbot

Run these commands to install the necessary tools:

Bash

```
sudo apt update
sudo apt install nginx python3-certbot-nginx -y
```

---

### 2. Configure Nginx for Each App

We will create a "Server Block" for each domain. I’ll provide the full component for **Brandflare**; you can simply duplicate this for the other two by changing the domain name and port numbers.

**Create the config file:**

Bash

```
sudo nano /etc/nginx/sites-available/brandflare
```

**Paste this configuration:**

Nginx

```
server {
    listen 80;
    # Replace with your actual domain
    server_name brandflarewoodworks.com www.brandflarewoodworks.com;

    # Frontend (Solid Start)
    location / {
        proxy_pass http://localhost:4001; 
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }

    # Backend API (Hono)
    # This allows your mobile app to call brandflarewoodworks.com/api
    location /api {
        proxy_pass http://localhost:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

_(Press `Ctrl+O`, `Enter`, then `Ctrl+X` to save and exit.)_

---

### 3. Enable the Configs

After creating files for all three (Brandflare, School, and Forex), you must tell Nginx to "activate" them.

Bash

```
# Link the files to the enabled folder
sudo ln -s /etc/nginx/sites-available/brandflare /etc/nginx/sites-enabled/
# Repeat for the others...

# Test if you made any typos
sudo nginx -t

# Restart Nginx to apply changes
sudo systemctl restart nginx
```

---

### 4. Secure with SSL (HTTPS)

Now for the "Security" part. Certbot will automatically talk to Let's Encrypt, verify you own the domain, and install the SSL certificates. It even updates the Nginx files for you automatically.

**Run this command for your domain:**

Bash

```
sudo certbot --nginx -d brandflarewoodworks.com -d www.brandflarewoodworks.com
```

- **Select "2"** if it asks whether to redirect HTTP to HTTPS (always choose Redirect).
    
- **Repeat** for `schoolsystem.com` and `forexhighway.com`.
    

---

### 5. Final VPS Security (The Firewall)

Since you are live, you should close all doors except for Web traffic and SSH.

Bash

```
# Allow SSH (so you don't lock yourself out!)
sudo ufw allow ssh

# Allow HTTP and HTTPS
sudo ufw allow 'Nginx Full'

# Enable the firewall
sudo ufw enable
```
