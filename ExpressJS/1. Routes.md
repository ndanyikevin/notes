
In **Express.js**, **routes** define **how your application responds to different HTTP requests (GET, POST, PUT, DELETE, etc.)** at specific URLs or endpoints.

Think of routes as **the “roads” of your backend** — each one tells Express what to do when a user visits a certain path.

---

### 🧠 Basic Concept

A **route** is made of three main parts:

1. **HTTP method** → GET, POST, PUT, DELETE
    
2. **Path (URL)** → `/`, `/users`, `/api/products/:id`, etc.
    
3. **Handler function** → the code that runs when the route is hit
    

---

### 🧩 Example

```js
import express from 'express';
const app = express();

// GET request — fetch data
app.get('/', (req, res) => {
  res.send('Welcome to my Express app!');
});

// POST request — create data
app.post('/users', (req, res) => {
  res.send('User created!');
});

// PUT request — update data
app.put('/users/:id', (req, res) => {
  res.send(`User ${req.params.id} updated`);
});

// DELETE request — delete data
app.delete('/users/:id', (req, res) => {
  res.send(`User ${req.params.id} deleted`);
});

app.listen(3000, () => console.log('Server running on port 3000'));
```

---

### 🧭 Route Parameters

Dynamic segments start with a colon `:`  
They let you handle variable paths (like user IDs):

```js
app.get('/users/:id', (req, res) => {
  const userId = req.params.id;
  res.send(`User ID: ${userId}`);
});
```

---

### 📦 Organizing Routes

In large apps, we separate routes into their own files using an **Express Router**.

**routes/userRoutes.js**

```js
import express from 'express';
const router = express.Router();

router.get('/', (req, res) => res.send('All users'));
router.post('/', (req, res) => res.send('Create user'));
router.get('/:id', (req, res) => res.send(`User ${req.params.id}`));

export default router;
```

**server.js**

```js
import express from 'express';
import userRoutes from './routes/userRoutes.js';

const app = express();
app.use('/users', userRoutes); // all routes start with /users

app.listen(3000, () => console.log('Server running on port 3000'));
```

---

### 🧾 Summary

|Term|Meaning|
|---|---|
|**Route**|Defines what happens when a request hits a specific path|
|**Router**|Mini express app to group related routes|
|**HTTP method**|Type of request (GET, POST, etc.)|
|**Path**|URL pattern (e.g., `/api/products/:id`)|
|**Handler**|Function that sends a response or performs logic|
