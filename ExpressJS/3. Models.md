
## 🧱 What Are **Models** in Express (or Node.js + MongoDB)?

A **model** represents the **data structure** of your application — basically how information is **stored in the database**.

In simple terms:

> **A model is a blueprint for your data.**

When using **MongoDB** with **Mongoose**, models define:

- What fields exist in your documents
    
- The type of each field
    
- Validation rules (e.g. required, unique, default)
    
- Relationships between data
    

---

### 🧩 Example: Defining a Model

Let’s say you’re building a user system.

**models/User.js**

```js
import mongoose from "mongoose";

const userSchema = new mongoose.Schema({
  name: {
    type: String,
    required: true,       // must be provided
  },
  email: {
    type: String,
    required: true,
    unique: true,         // no duplicates allowed
  },
  password: {
    type: String,
    required: true,
  },
  createdAt: {
    type: Date,
    default: Date.now,    // auto-assign current date
  },
});

// Create and export model
const User = mongoose.model("User", userSchema);
export default User;
```

This defines how a **user document** looks inside MongoDB:

```json
{
  "name": "Kevin",
  "email": "kevin@example.com",
  "password": "hashedpassword123",
  "createdAt": "2025-11-06T00:00:00.000Z"
}
```

---

### 🧠 How It Fits Together

Here’s the flow of a request in an Express + MongoDB app:

```
Client → Route → Controller → Model → Database
```

Let’s visualize it:

|Layer|Role|
|---|---|
|**Route**|Listens for requests (`POST /users`)|
|**Controller**|Runs logic (`create a new user`)|
|**Model**|Talks to MongoDB (`User.create(...)`)|
|**MongoDB**|Actually stores the data|

---

### ⚙️ Example: Using the Model in a Controller

**controllers/userController.js**

```js
import User from "../models/User.js";

export const createUser = async (req, res) => {
  try {
    const { name, email, password } = req.body;

    // create a user using the model
    const user = await User.create({ name, email, password });

    res.status(201).json({ message: "User created", user });
  } catch (err) {
    res.status(400).json({ error: err.message });
  }
};
```

---

### 📦 Summary

|Concept|Description|
|---|---|
|**Model**|Defines structure & behavior of data|
|**Schema**|Blueprint (field types, validation, defaults)|
|**Mongoose**|Library that connects Node.js models to MongoDB|
|**Document**|A record in MongoDB created from a model|

---

### 🧩 MVC Pattern in Express

```
project/
├── models/
│   └── User.js         ← defines the data structure
├── controllers/
│   └── userController.js  ← handles logic using the model
├── routes/
│   └── userRoutes.js   ← defines endpoints
└── server.js           ← main app setup
```
