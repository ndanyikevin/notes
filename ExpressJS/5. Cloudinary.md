
## 🌤️ What is Cloudinary?

[Cloudinary](https://cloudinary.com/) is a cloud service that lets you easily **upload, store, and deliver** images, videos, and other media — with automatic optimization, resizing, and transformations.

---

## ⚙️ Step 1: Create a Cloudinary Account

1. Go to [https://cloudinary.com/users/register](https://cloudinary.com/users/register)
    
2. After signup, you’ll get your **Cloudinary credentials**:
    
    - **Cloud name**
        
    - **API key**
        
    - **API secret**
        

You can find these in your Cloudinary Dashboard → “Account Details”.

---

## 🧾 Step 2: Install Required Packages

```bash
npm install cloudinary multer dotenv
```

- `cloudinary` → connects your app to Cloudinary API
    
- `multer` → handles file uploads from forms or API clients
    
- `dotenv` → loads your Cloudinary credentials securely from `.env`
    

---

## 🔐 Step 3: Setup `.env` File

Create a `.env` file in your project root and add:

```env
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
```

---

## 🧠 Step 4: Configure Cloudinary in Your App

**config/cloudinary.js**

```js
import { v2 as cloudinary } from 'cloudinary';
import dotenv from 'dotenv';

dotenv.config();

cloudinary.config({
  cloud_name: process.env.CLOUDINARY_CLOUD_NAME,
  api_key: process.env.CLOUDINARY_API_KEY,
  api_secret: process.env.CLOUDINARY_API_SECRET,
});

export default cloudinary;
```

---

## 📤 Step 5: Handle File Uploads

You can use **Multer** to accept files from the client.

**middleware/multer.js**

```js
import multer from 'multer';

// Store file temporarily in memory
const storage = multer.memoryStorage();
const upload = multer({ storage });

export default upload;
```

---

## 🚀 Step 6: Create an Upload Route

**routes/uploadRoutes.js**

```js
import express from 'express';
import upload from '../middleware/multer.js';
import cloudinary from '../config/cloudinary.js';
import fs from 'fs';

const router = express.Router();

// Upload image to Cloudinary
router.post('/', upload.single('image'), async (req, res) => {
  try {
    const fileBuffer = req.file.buffer;

    // Upload directly from buffer (requires temp file)
    const result = await cloudinary.uploader.upload_stream(
      { folder: 'uploads' },
      (error, result) => {
        if (error) return res.status(500).json({ error });
        res.json({
          message: 'Uploaded successfully',
          url: result.secure_url,
          public_id: result.public_id,
        });
      }
    ).end(fileBuffer);

  } catch (err) {
    res.status(500).json({ error: err.message });
  }
});

export default router;
```

---

## 🧩 Step 7: Mount the Route in `server.js`

```js
import express from 'express';
import uploadRoutes from './routes/uploadRoutes.js';
import dotenv from 'dotenv';

dotenv.config();
const app = express();

app.use(express.json());
app.use('/upload', uploadRoutes);

app.listen(3000, () => console.log('Server running on port 3000'));
```

---

## 🧪 Step 8: Test It!

Use **Postman** or **Thunder Client**:

- Method: `POST`
    
- URL: `http://localhost:3000/upload`
    
- Body → `form-data`
    
    - Key: `image`
        
    - Type: `File`
        
    - Value: select an image file
        

✅ If successful, Cloudinary will return:

```json
{
  "message": "Uploaded successfully",
  "url": "https://res.cloudinary.com/yourname/image/upload/v12345/uploads/photo.jpg",
  "public_id": "uploads/photo"
}
```
