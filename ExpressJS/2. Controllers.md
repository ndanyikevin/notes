
In **Express.js**, **controllers** are the functions (or modules) that contain the **actual logic for handling a request** — separate from the routing setup.

They’re the **“brains”** behind your routes.  
While **routes** decide _where_ a request goes, **controllers** decide _what happens_ once it gets there.

---

### 🧩 In simple terms:

- **Routes** = define the path (e.g. `/users`, `/products/:id`)
    
- **Controllers** = define the logic (e.g. get all users, create a user, delete product)
    

---

### 💡 Why use controllers?

Keeping logic inside route files quickly becomes messy.  
Controllers help you:

- Organize your code (clean and modular)
    
- Reuse logic
    
- Follow the **MVC (Model–View–Controller)** pattern
    

---

### 🧠 Example: Routes vs Controllers

#### 🪜 1. Route file — `routes/userRoutes.js`

```js
import express from 'express';
import { getUsers, createUser } from '../controllers/userController.js';

const router = express.Router();

router.get('/', getUsers);       // GET /users
router.post('/', createUser);    // POST /users

export default router;
```

#### ⚙️ 2. Controller file — `controllers/userController.js`

```js
export const getUsers = (req, res) => {
  // logic to get users from database
  res.json([
    { id: 1, name: 'Kevin' },
    { id: 2, name: 'John' }
  ]);
};

export const createUser = (req, res) => {
  // logic to create a user in database
  const { name } = req.body;
  res.status(201).json({ message: `User ${name} created` });
};
```

#### 🚀 3. Main app — `server.js`

```js
import express from 'express';
import userRoutes from './routes/userRoutes.js';

const app = express();
app.use(express.json());

app.use('/users', userRoutes);

app.listen(3000, () => console.log('Server running on port 3000'));
```

---

### 🧾 Summary

|Concept|Description|
|---|---|
|**Route**|Defines the endpoint and HTTP method (`GET /users`, `POST /users`)|
|**Controller**|Handles the request logic and response|
|**Separation of Concerns**|Makes your app cleaner, scalable, and easier to maintain|

---

### 💪 Example structure (recommended)

