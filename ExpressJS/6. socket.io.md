
## ⚡ What is Socket.IO?

**Socket.IO** is a library that enables **real-time, bidirectional communication** between your **client (browser or mobile app)** and your **server (Express.js)**.

In short:

> It lets your app **send and receive data instantly** without refreshing the page.

---

### 🧠 How It Works

- Normally, HTTP requests are **one-way**: client → server.
    
- With **WebSockets (used by Socket.IO)**, both client and server can talk **continuously**.
    

So, when something happens on the server (e.g., a new message, live update, or notification), the client gets it **instantly**.

## 🧩 Step 2: Setup Socket.IO in Express

Here’s a minimal example 👇

**server.js**

```js
import express from 'express';
import http from 'http';
import { Server } from 'socket.io';

const app = express();
const server = http.createServer(app); // create a raw HTTP server
const io = new Server(server, {
  cors: {
    origin: '*', // allow all origins (for testing)
  },
});

app.get('/', (req, res) => {
  res.send('Socket.IO Server running');
});

// Handle socket connections
io.on('connection', (socket) => {
  console.log('🟢 A user connected:', socket.id);

  // Receive message from client
  socket.on('chat message', (msg) => {
    console.log('💬 Message:', msg);

    // Broadcast message to all connected clients
    io.emit('chat message', msg);
  });

  socket.on('disconnect', () => {
    console.log('🔴 User disconnected:', socket.id);
  });
});

server.listen(3000, () => console.log('Server running on port 3000'));
```

## 💻 Step 3: Client-Side Code Example

You can test it in an HTML file:

**index.html**

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Socket.IO Chat</title>
  </head>
  <body>
    <h2>Socket.IO Chat</h2>
    <input id="msg" placeholder="Type a message" />
    <button id="sendBtn">Send</button>

    <ul id="messages"></ul>

    <script src="https://cdn.socket.io/4.7.2/socket.io.min.js"></script>
    <script>
      const socket = io('http://localhost:3000');

      document.getElementById('sendBtn').onclick = () => {
        const msg = document.getElementById('msg').value;
        socket.emit('chat message', msg);
        document.getElementById('msg').value = '';
      };

      socket.on('chat message', (msg) => {
        const li = document.createElement('li');
        li.textContent = msg;
        document.getElementById('messages').appendChild(li);
      });
    </script>
  </body>
</html>
```

Then open **two browser tabs** — type messages — and you’ll see them appear in both instantly ⚡

## 🧠 Summary

|Concept|Explanation|
|---|---|
|**Socket.IO**|Real-time communication framework|
|**Server**|Listens for and emits events|
|**Client**|Connects and listens to events|
|**Event**|A named message (`'chat message'`, `'disconnect'`, etc.)|
|**Broadcast**|Send data to all clients instantly|
