
## 🧠 What `aggregate()` Does

The `.aggregate()` function lets you perform **powerful data processing and transformations directly inside MongoDB** — like grouping, filtering, sorting, joining, counting, and calculating averages.

Think of it as MongoDB’s version of SQL’s **`GROUP BY`, `JOIN`, and `WHERE`** combined — but even more flexible.

> It processes your data **through a pipeline** of stages, where each stage transforms the output of the previous one.

---

## 🧩 Example Scenario

Let’s say you have a **Post** collection like this:

```json
[
  { "title": "Post 1", "author": "Alice", "likes": 10 },
  { "title": "Post 2", "author": "Bob", "likes": 5 },
  { "title": "Post 3", "author": "Alice", "likes": 20 }
]
```

---

## ⚙️ Basic Example

```js
const result = await Post.aggregate([
  {
    $group: {
      _id: "$author",          // group by author
      totalLikes: { $sum: "$likes" }, // sum likes per author
      postCount: { $sum: 1 }          // count posts
    }
  }
]);

console.log(result);
```

**Output:**

```json
[
  { "_id": "Alice", "totalLikes": 30, "postCount": 2 },
  { "_id": "Bob", "totalLikes": 5, "postCount": 1 }
]
```

🧠 So, Alice has 2 posts and 30 total likes.

---

## 🧱 Common Aggregation Stages

|Stage|Description|Example|
|---|---|---|
|`$match`|Filters documents (like `find()`)|`{ $match: { author: "Alice" } }`|
|`$group`|Groups by a field, performs sums/counts|`{ $group: { _id: "$author", total: { $sum: "$likes" } } }`|
|`$sort`|Sorts documents|`{ $sort: { totalLikes: -1 } }`|
|`$project`|Selects or reshapes fields|`{ $project: { title: 1, likes: 1 } }`|
|`$limit`|Limits the number of results|`{ $limit: 5 }`|
|`$skip`|Skips a number of results (for pagination)|`{ $skip: 10 }`|
|`$lookup`|Joins another collection (like SQL JOIN)|`{ $lookup: { from: "users", localField: "authorId", foreignField: "_id", as: "author" } }`|
|`$unwind`|Deconstructs arrays into individual documents|`{ $unwind: "$tags" }`|

---

## 💡 Example: Using `$match`, `$group`, and `$sort` Together

```js
const result = await Post.aggregate([
  { $match: { likes: { $gte: 5 } } }, // only posts with 5+ likes
  { $group: { _id: "$author", totalLikes: { $sum: "$likes" } } },
  { $sort: { totalLikes: -1 } }       // sort by total likes desc
]);
```

---

## 🔗 Example: Joining Two Collections with `$lookup`

Let’s say you have `users` and `posts`.

**User Schema**

```js
{ _id: 1, name: "Kevin" }
```

**Post Schema**

```js
{ title: "Hello", authorId: 1 }
```

You can join them like this:

```js
const result = await Post.aggregate([
  {
    $lookup: {
      from: "users",          // collection to join
      localField: "authorId", // field in Post
      foreignField: "_id",    // field in User
      as: "authorInfo"        // alias for joined data
    }
  }
]);

console.log(result);
```

Output:

```json
[
  {
    "title": "Hello",
    "authorId": 1,
    "authorInfo": [
      { "_id": 1, "name": "Kevin" }
    ]
  }
]
```

## ⚡ Example: Average Likes Per User

```js
const avgLikes = await Post.aggregate([
  { $group: { _id: "$author", avgLikes: { $avg: "$likes" } } }
]);
```

---

## 🧾 Summary

|Concept|Description|
|---|---|
|**`aggregate()`**|Runs an aggregation pipeline to process and analyze data|
|**Pipeline**|Array of stages that transform data step-by-step|
|**$match**|Filters documents|
|**$group**|Groups and performs calculations|
|**$lookup**|Joins collections|
|**$project**|Shapes the final output|

---

## 💪 When to Use `aggregate()`

Use it when you need:

- Statistics (totals, averages, counts)
    
- Analytics dashboards
    
- Complex filters + groupings
    
- Data joins between collections
    
- Pagination or transformations directly in MongoDB
