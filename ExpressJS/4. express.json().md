
## 🧠 What `express.json()` Does

`express.json()` is a **built-in middleware** in Express that allows your server to **parse incoming JSON data** in the body of HTTP requests.

In short:

> It lets your Express app understand and read `req.body` when the client sends JSON data.

---

### 🧩 Without `express.json()`

Let’s say a client sends this request:

```http
POST /users
Content-Type: application/json

{
  "name": "Kevin",
  "email": "kevin@example.com"
}
```

If you don’t use `express.json()`, this is what happens inside your route:

```js
app.post('/users', (req, res) => {
  console.log(req.body); // ❌ undefined
});
```

The server **won’t understand the JSON** — `req.body` will be `undefined`.

---

### ✅ With `express.json()`

When you add this line:

```js
app.use(express.json());
```

Express will automatically:

1. Look at the request’s `Content-Type` header (if it’s `application/json`)
    
2. Parse the raw JSON data into a JavaScript object
    
3. Attach it to `req.body`
    

So now:

```js
app.post('/users', (req, res) => {
  console.log(req.body); // ✅ { name: 'Kevin', email: 'kevin@example.com' }
  res.send('User received!');
});
```

---

### 💡 When to Use It

Add it once in your main app (usually `server.js` or `app.js`):

```js
import express from 'express';

const app = express();

// Parse incoming JSON requests
app.use(express.json());
```

Then all your routes can access `req.body` normally.

---

### ⚙️ Other Common Middleware (for comparison)

|Middleware|Purpose|
|---|---|
|`express.json()`|Parses JSON data|
|`express.urlencoded({ extended: true })`|Parses form data (from HTML forms)|
|`cors()`|Enables cross-origin requests|
|`morgan('dev')`|Logs requests to console|

---

### 🧾 Summary

|Concept|Explanation|
|---|---|
|**Type**|Built-in Express middleware|
|**Purpose**|Parse incoming JSON request bodies|
|**Effect**|Makes `req.body` available as a JS object|
|**Required for**|APIs that receive JSON (like POST, PUT, PATCH requests)|
