Adding **Inference Types** and **Soft Deletes** is a professional-grade move. In a multi-tenant school system, you almost never want to permanently delete data (especially marks/scores); soft deletes allow you to recover records if a teacher accidentally deletes the wrong CAT entry.

Here is the updated schema with the Drizzle `Infer` types and the `deletedAt` column.

### Updated 8-4-4 Scores Schema

**`src/db/schema/academics/assessments_844.ts`**

TypeScript

```
import { pgTable, serial, integer, uuid, text, timestamp, pgEnum } from "drizzle-orm/pg-core";
import { relations, type InferSelectModel, type InferInsertModel } from "drizzle-orm";
import { schools } from "../schools.js";
import { students } from "../users/students.js";
import { subjects } from "./subjects.js";
import { terms } from "./calendar.js";

export const assessmentType844 = pgEnum("assessment_type_844", ["CAT_1", "CAT_2", "END_OF_TERM"]);

export const scores844 = pgTable("scores_844", {
  id: serial("id").primaryKey(),
  schoolId: uuid("school_id").notNull().references(() => schools.id),
  studentId: text("student_id").notNull().references(() => students.id),
  subjectId: integer("subject_id").notNull().references(() => subjects.id),
  termId: integer("term_id").notNull().references(() => terms.id),
  type: assessmentType844("type").notNull(),
  score: integer("score").notNull(),
  createdAt: timestamp("created_at").defaultNow().notNull(),
  updatedAt: timestamp("updated_at").defaultNow().notNull(),
  deletedAt: timestamp("deleted_at"), // For Soft Deletes
});

// Relations
export const scores844Relations = relations(scores844, ({ one }) => ({
  school: one(schools, { fields: [scores844.schoolId], references: [schools.id] }),
  student: one(students, { fields: [scores844.studentId], references: [students.id] }),
  subject: one(subjects, { fields: [scores844.subjectId], references: [subjects.id] }),
  term: one(terms, { fields: [scores844.termId], references: [terms.id] }),
}));

// Inference Types
export type Score844 = InferSelectModel<typeof scores844>;
export type NewScore844 = InferInsertModel<typeof scores844>;
```

### Implementation: Using Soft Deletes in Services

Since you are using a `deleted_at` column, you need to ensure your queries filter out "deleted" rows.

#### 1. The Service Logic

You can update your `BaseService` or specific services to handle this automatically.

TypeScript

```
// Example of a find query with soft-delete filter
async findActiveScores(schoolId: string) {
  return await db.select()
    .from(scores844)
    .where(
      and(
        eq(scores844.schoolId, schoolId),
        isNull(scores844.deletedAt) // Only fetch records that aren't soft-deleted
      )
    );
}

// Example of performing the soft delete
async softDeleteScore(id: number, schoolId: string) {
  return await db.update(scores844)
    .set({ deletedAt: new Date() })
    .where(
      and(eq(scores844.id, id), eq(scores844.schoolId, schoolId))
    );
}
```

### A Quick Note on `updatedAt`

In Postgres, `defaultNow()` only sets the time when the record is **created**. To make `updatedAt` change every time you modify a score, you usually need a small Postgres trigger or manually set it in your Drizzle `.set({ updatedAt: new Date() })` call.
