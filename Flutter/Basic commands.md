### Setting Up

```
flutter doctor
```

### Creating a New Project
---
```
flutter create my_app
```

If you want to include your organization's name in the project, you can do like this

```
flutter create --org com.yourdomain appname
```

### Running the App
---
```
flutter run
```

### Checking Installed Devices
---
```
flutter devices
```

### Building Apk for Android
---
```
flutter build apk
```

### Building IPA for IOS
---
```
flutter build ios
```

### Get All Packages
---
```
flutter pub get
```
